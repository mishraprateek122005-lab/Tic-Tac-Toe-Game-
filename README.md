# 🎮 Tic Tac Toe Game Using Python

### Play • Think • Win 🚀

## 📌 About This Project

Tic Tac Toe is a simple and interesting two-player game made using Python.

In this game, two players play against each other using X and O symbols on a 3×3 board. Each player gets one turn at a time to select an empty position.

The main goal is to make three same symbols in a straight line (horizontal, vertical, or diagonal) to win the game.

This project is created to practice Python programming and improve logical thinking and problem-solving skills.

## 🎯 How This Game Works

1. First, a 3×3 game board is created.
2. Two players choose their symbols: X and O.
3. Players select their positions one by one.
4. The game updates the board after every move.
5. The program checks whether a player has won.
6. If three same symbols come in a straight line, the player wins.
7. If all positions are filled and nobody wins, the game ends in a draw.

---

## 🏆 Winning Rules

A player can win in three ways:

- **Row:** Three same symbols in one horizontal line.
- **Column:** Three same symbols in one vertical line.
- **Diagonal:** Three same symbols in a diagonal line.
